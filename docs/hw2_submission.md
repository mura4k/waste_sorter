## Что реально выполнено

- Декодированы все 2 527 JPEG TrashNet, проверены размеры, качество, EXIF и дубли.
- Проанализированы 4 784 аннотации и 1 500 сцен TACO; сами фото TACO не загружены.
- Зафиксированы URL/revision/SHA-256 источников, mapping и окружение.
- Обнаружены 3 точные пары с противоречащими метками, 137 неоднозначных `trash`,
  отсутствие трёх целевых классов; в TACO — дефекты bbox/ID и незавершённые сведения о правах.
- Построены manifest и предварительный split, выполнен визуальный скрининг.
- На четырёх материалах посчитаны B0 и цветовой baseline:
  validation macro-F1 0.1464 и 0.5966. Модельный test не использован.
- Расширены подробные этапы; прописаны условия остановки и ограничения запуска.
- Проверены повторяемость артефактов, 15 тестов, Ruff и форматирование.

## Ограничения, которые важно учитывать при ревью

Это не готовый семиклассовый продукт. Группы dHash не равны проверенным предметам;
у них есть ложные совпадения и пропуски. Снимки новых реальных предметов, независимая
экспертная разметка, полностью установленная лицензионная база TACO, проверенный
профиль площадки, CNN и пользовательский пилот ещё нужны. Эти пункты отражены
в плане, а не объявлены выполненными. Недостаток покрытия выявлен в EDA и не скрыт
ресэмплингом или выдуманными примерами.

## Воспроизведение

```bash
pip install -c requirements/hw2.txt -e ".[dev,eda]"
python scripts/download_data.py
python -m waste_sorter.eda
python -m waste_sorter.baseline
pytest -q
ruff check .
ruff format --check .
pre-commit run --all-files
```

Нужен Python 3.11+ и интернет только для установки/первой загрузки данных.
Сырые данные остаются вне git. Ментора и кросс-ревьюверов нужно назначить
в PR по списку курса; их имена в задании не указаны.
