# Профиль пилота: Москва, схема ЭкоЛайн

Статус `moscow-ecoline-draft-v1`: проект справочника, а не включённая функция API.
Выбор сделан для ограничения дизайна одним городом и одной схемой приёма.
Не распространяется автоматически на другие площадки Москвы и области.

Основание: [правила раздельного сбора исполнителя ЭкоЛайн](https://ec-line.ru/rso/).
Страница перечисляет стекло, металл, пластик, макулатуру и Tetra Pak для синего
контейнера и выделяет специальные пункты для опасных отходов. Проверка ссылки
при подготовке дизайна — 05.11.2026; подробный профиль и условия конкретной площадки
до пилота ещё должны быть сверены с исполнителем. Наличие общей категории
в списке не означает, что принимается любое изделие из этого материала.

| Предсказание материала | Условие уточнения | Маршрут в проекте профиля |
|---|---|---|
| `paper` | Обычная чистая сухая бумага/картон; подтверждено, что не чек и не композит | Синий контейнер после проверки исключений |
| `glass` | Подтверждена стеклянная тара; не керамика, зеркало или специальное стекло | Синий контейнер после проверки исключений |
| `metal` | Подтверждена бытовая тара; не батарейка/электроника | Синий контейнер после проверки исключений |
| `plastic` | Есть маркировка и подтверждение приёма данного изделия | Синий контейнер только по проверенной записи; иначе `unknown` |
| `organic` | Пищевые отходы; отдельный сбор на площадке не подтверждён | Не в синий; точный маршрут сверить, иначе `unknown` |
| `hazardous` | Возможная батарейка или иной опасный предмет | Предупреждение; отдельный специальный пункт, не обычный контейнер |
| `other` | Материал вне поддерживаемых категорий | Уточнение предмета; `unknown`, не автоматическое «в смешанные» |

Для чека, керамики, композита и неизвестного полимера одной вероятности класса
недостаточно. Пользователю нужен вопрос о составе/маркировке или справочник.
Tetra Pak не маппится автоматически из `paper`: до подтверждения изделия и условий
выбранной площадки возвращается неопределённость.

Профиль считается готовым для пилота, когда записаны адрес площадки, актуальный
источник, дата сверки, проверяющий, перечень изделий/исключений и конкретные пункты
специального сбора. Метка `rejected` означает отказ выбранной схемы принять
конкретное изделие, а не невозможность его переработки вообще. Пока эти поля
не заполнены, приложение не выдаёт окончательные маршруты и не заявляет измерение
корректности инструкций. Эталон пилота содержит подтверждённый маршрут для каждого
предмета отдельно; класс нейросети не заменяет эту разметку.
