# Исправления после ревью ДЗ1

Ревью: 8.5/10. Ниже отражены изменения дизайна и каркаса; будущие проверки
не выдаются за уже выполненные эксперименты.

| Замечание | Исправление | Что ещё требуется |
|---|---|---|
| Подтверждения пользователей не доказывают правильность | Независимый эталон; аудит перед train; фидбэк отдельно | Собрать контрольные фото и назначить проверяющего |
| Бизнес-цель не измеряется | Сравнение со справочником по верным решениям и времени; 20 заданий на участника | Малый пилот даёт usability, для вывода об эффекте нужен размер выборки |
| Опасные отходы теряются за top-1 | Приоритетный порог, recall предупреждения после правила, отдельные отказы/top-3 | Проверить на батарейках; лампы и техника пока вне обещаний распознавания |
| WaDaBa не покрывает LDPE/PVC и Other | Четыре кандидата PET/HDPE/PP/PS; расширение не блокирует MVP | Доступ по условиям выдачи, аудит снимка и собственные маркированные предметы |
| Ракурсы одного предмета попадают в разные split | Группы предметов/сцен, дедупликация до split, train-only аугментации | Реализовать manifest и проверки утечки при сборе данных |
| Модель может узнать источник | Срезы по источникам и leave-one-dataset-out | Показать ограничения классов, имеющихся только в одном источнике |
| TACO одновременно train и test | Только challenge; RealWaste тоже внешний; свои test-фото отдельно от фидбэка | Проверить mapping, права и состав конкретных версий |
| Внутренняя метрика не означает качество на телефоне | Раздельные цели F1 0.85/0.75; реальная validation для порогов | Проверить совместимость precision, coverage и защитных ограничений |
| Чеки, керамика, композиты, посторонние фото | Отдельный challenge 30–50 случаев, уточнение и отказ; цикл пересъёмки | Не обещать успешный детектор неподдерживаемых фото до проверки |
| Регион не выбран | Москва, проект профиля схемы ЭкоЛайн | Подтвердить площадку и исключения до запуска советов |
| Подсказки и `non_recyclable` вводят в заблуждение | Условные подсказки; `Acceptance` с `unknown`; удалён универсальный bool | Профиль должен учитывать изделие и состояние, не только полимер |
| Цена ошибок не отражена | Матрица относительных приоритетов, защитные метрики и порядок правил | Не заявлять выдуманную денежную оценку ущерба |
| Латентность API и инференса смешаны | Раздельные границы замеров; план клиентского сжатия | Нагрузочный и сетевой замеры после реализации сервиса |
| В схемах нет test и согласия | Закрытые test/challenge, ветка неуспеха, согласие перед сохранением | Реализовать в последующих итерациях |
| Приватность и лицензии | Исключение людей/документов, срок 30 дней, удаление; аудит прав по источникам | Не переносить исследовательские данные в коммерческий сценарий без проверки |
| README и проверки через веб | Команды проверок, честный статус, Python 3.11+, CI 3.11/3.12 | Успешный CI не является оценкой качества ML |

## Основания и границы проверки источников

- [Условие ДЗ1](https://gist.github.com/pacifikus/47424379293e0874859354ecd130ba13).
- Предоставленные занятия MLSD 1–6: ценность/метрики, аудит данных, независимость
  разбиения, обратная связь и сравнение моделей.
- [RealWaste, UCI](https://archive.ics.uci.edu/dataset/908/realwaste): реальные условия,
  девять исходных классов и CC BY 4.0; hazardous отсутствует в списке классов.
- [Исследование WaDaBa](https://www.oaepublish.com/articles/ir.2021.15): отсутствие
  PVC/LDPE, малый Other, повторяемая съёмка. Количества в этой статье и в ревью
  различаются: итоговые counts определяет аудит полученной версии, не догадка.
- [Описание автора Garbage Classification](https://www.kaggle.com/code/mostafaabla/garbage-classification-keras-transfer-learning/input):
  веб-происхождение, обычная одежда и исследовательский контекст.
- [TACO](https://github.com/pedropro/TACO): сцены и COCO-аннотации;
  лицензия toolkit не заменяет проверку прав на фотографии.
- [Схема ЭкоЛайн](https://ec-line.ru/rso/): основание проекта московского профиля.

Точные численные составы наборов, переданные ревьюером, не объявлены результатами
нашего EDA. Статистика внешних статей не заменяет независимую проверку проекта.
