# Waste Sorter 

ML-сервис, который по фотографии предмета определяет, к какой фракции (далее типу) отходов он относится
(пластик, бумага, стекло, металл, органика, опасные отходы, прочее).

## Зачем

Люди хотят сортировать мусор, но часто не знают, куда отнести конкретный предмет:
чек, тетрапак, разбитую кружку. Ошибки загрязняют вторсырьё, и партия может уйти на полигон.
Сервис снимает этот барьер: сфотографировал и получил ответ за секунду.

## Как это будет работать

1. Пользователь фотографирует предмет в веб- или мобильном приложении.
2. Изображение уходит в API (FastAPI).
3. CNN-классификатор (transfer learning, например EfficientNet / MobileNetV3) возвращает
   класс и уверенность.
4. Если это пластик, вторая голова модели определяет тип пластика и признак
   «перерабатывается / нет».
5. Приложение показывает фракцию (и тип пластика). При низкой уверенности просит переснять
   фото или выбрать класс вручную; эти ответы пополняют датасет.

Подробности в [дизайн-документе](docs/ml_system_design_doc.md).
